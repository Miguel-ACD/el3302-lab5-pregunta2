# Producto

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegado: Flask, PostgreSQL y Docker Compose para una práctica sencilla.

## Users
Estudiante que demuestra una campaña de marketing a partir de una foto.

## Product Purpose
Recibir una foto, proponer tres guiones, seleccionar uno, generar tres piezas visuales y un video, y preparar o realizar la publicación en Instagram.

## Operating Context
Laboratorio académico con evidencias de funcionamiento, despliegue en AWS y video de demostración de hasta cinco minutos.

## Capabilities and Constraints
Interfaz simple y presentable. La generación debe responder sin errores de tiempo; un proceso separado crea los archivos. La cuenta de Instagram de prueba es personal y aún no está configurada para publicar mediante la API oficial.

## Product Principles
Mostrar cada etapa de forma clara. Indicar los errores en pantalla. Conservar los resultados en la base de datos y en un volumen.
